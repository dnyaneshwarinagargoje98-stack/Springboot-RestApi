# Spring Boot REST API

This is a simple Spring Boot CRUD REST API project.

## Features
- Create User
- Get User
- Update User
- Delete User

## Technologies Used
- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Maven

## API Endpoints

| Method | Endpoint |
|--------|----------|
| POST | /users |
| GET | /users |
| PUT | /users/{id} |
| DELETE | /users/{id} |

## Run Project

```bash
mvn spring-boot:run
